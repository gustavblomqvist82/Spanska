# Projektinstruktioner

Det här repot innehåller en svensk webbplats för att lära sig spanska.

## Arbetsflöde för alla konversationer i projektet

- Behandla GitHub-repot `gustavblomqvist82/Spanska` som den gemensamma källan för projektets aktuella filer. Kontrollera aktuell gren och öppna pull requests innan du redigerar; utgå inte från att den lokala mappen är uppdaterad.
- Gör ändringar via den anslutna GitHub-integrationen på en separat gren med prefixet `codex/`. Öppna en pull request mot `main` och låt Vercel skapa en förhandsvisning. Redovisa PR-länken samt förhandsvisningens status och URL.
- Ändra inte `main`, slå inte samman en pull request och publicera inte manuellt till produktion om användaren inte uttryckligen ber om det.
- Använd anslutningarna till GitHub och Vercel i stället för att ta över användarens dator. Bygg ingen egen API-brygga för publicering om användaren inte ber om det.
- Om en anslutning eller behörighet kräver användarens åtgärd, visa den konkreta åtgärden och fortsätt när den är klar.
- Läs `SOURCES.md` före ändringar som påverkar orddata eller källhänvisningar. Läs `kom ihåg lista.md` när du planerar eller genomför kommande spel och lärandefunktioner.

## Kunskap och pedagogik

- Utgå från Skolverkets kursplan i moderna språk. Behandla slutet av årskurs 6 och 9 som officiella målgränser; nivåer för årskurs 7–8 är webbplatsens egen progression och får inte presenteras som officiella krav.
- Övningar ska träna relevanta färdigheter i spanska, såsom hörförståelse, läsning, muntlig och skriftlig produktion samt interaktion. Förklara vad spelaren kan efter varje nivå.
- Beskriv spelresultat som resultat på övningen, aldrig som ett skolbetyg.

## Orddata och källor

- Bevara Lexins källhänvisning och CC BY 4.0-attribution enligt `SOURCES.md`. Nya eller ändrade Lexin-poster ska behålla spårbar källa och dokumentera urval eller bearbetningar.
- Ordlistans spelmetadata och svårighetsnivåer är webbplatsens egna; likställ dem inte automatiskt med officiella skolår eller betyg.
